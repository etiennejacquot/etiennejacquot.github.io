Recommendations

Papers, books, and tools I return to.

Papers

  • Raissi, Perdikaris & Karniadakis (2019) — Physics-informed neural networks. The paper that started the PINN literature; still the clearest statement of the variational idea.
  • Saad & Schultz (1986) — GMRES: A generalized minimal residual algorithm. Essential reading before tuning any Krylov solver for CFD.
  • Linka et al. (2023) — Automated model discovery for soft matter. Compact introduction to constitutive neural networks; the CANN idea scales directly to solid mechanics.

Books

  • Trefethen & Bau — Numerical Linear Algebra. The fastest route from linear algebra basics to preconditioning intuition; I re-read chapters 32–35 before every sparse-solver project.
  • Pope — Turbulent Flows. Self-contained and precise; Chapters 9–10 on LES are indispensable if you work with filtered Navier–Stokes.
  • Goodfellow, Bengio & Courville — Deep Learning. Chapter 6 (backprop) and Chapter 8 (optimisation) are the ones to re-read when a training run diverges.

Tools

  • JAX — Just-in-time compilation + automatic differentiation in NumPy syntax. The right default for research code that needs to go fast without a rewrite.
  • Trilinos / ML AMG — Algebraic multigrid that actually works on saddle-point systems. Configuration is painful; the payoff in convergence rate is real.
  • nekRS — GPU-native spectral-element CFD solver built on OCCA. Near-ideal for GPU-cluster turbulence studies once the mesh pipeline is set up.
